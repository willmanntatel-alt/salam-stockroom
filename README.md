# Salam Stockroom

A local inventory and pack-aware replenishment planner built with the
[Salam Programming Language](https://github.com/SalamLang/Salam).

Development starts with bounded integer counts and exact minor-unit money.
The next milestones add CSV import, demand-based planning, budget allocation,
and reviewable reports. All examples will use fictional stock, not user data.

AI assistance: OpenAI Codex is used for implementation and verification.
